# Security Policy

## Reporting Security Vulnerabilities

We take the security of Clared and autonomous agent execution boundaries seriously.

If you believe you have discovered a vulnerability, bypass, or state leak in Clared:

1. **Do not create a public GitHub issue.**
2. Send a report directly to: `security@clared.ai`
3. Include:
   - A description of the vulnerability (such as capability token forgery, transaction isolation escape, or WAL race condition).
   - Minimal reproduction code or test payload.
   - Expected vs actual execution behavior.

We acknowledge reports within 48 hours and work on remediation before public disclosure.
